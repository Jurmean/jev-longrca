# Adaptive JEV-RCTA v3.1：停止后的离线分析

范围：2026-09-24 完成的 100 条 Mini（40 条 SWE-Bench Pro、40 条 Terminal-Bench、18 条 TravelPlanner，VitaBench 和 WebArena 各 1 条）。不是完整 Mini 或未见留出集。本分析仅读取已保存结果，没有新增 API 调用。

## 主要发现

| 阶段 | 正确步骤保留或命中的样本数 |
|---|---:|
| 模型输入中出现正确步骤的至少一段原文 | 63/100 |
| 正确步骤被作为目标实际检查 | 28/100 |
| 正确步骤进入最终候选 | 28/100 |
| 核验前最终选择正确 | 11/100 |
| 核验后最终预测正确 | 10/100 |

出现原文片段不等于完整因果证据已经齐全。baseline 做对而新版做错的 14 条中，有 10 条的正确步骤没有进入新版最终候选；因此主要损失不能只归因于末尾核验或弃答阈值。

## 架构层面的解释

1. **过早收窄候选。** 最终候选不含正确步骤的 72 条，无法在当前答案空间内精确答对。
2. **局部分类未组成可靠的因果关系。** 检索相关片段、标注局部现象、判断上游或修复，并不自动保留任务要求、交接、执行和最终影响之间的关系。
3. **置信度尚未转化为可靠的搜索策略。** 本次全部采用未经校准的启发式规则。轨迹步骤数中位数为 204，实际每条仅检查 2–4 个目标步骤；概率主要用于排序，不能视为全局正确率保证。
4. **覆盖与预算存在冲突。** 98 条为预留最终判断预算而结束搜索，并非已取得充分证据。已完成样本输入 tokens 为 5,831,124，约为同样本历史 baseline 的 28.2%；缺少同预算对照，不能精确分离压缩和架构改动的贡献。
5. **严格核验目标更苛刻，但不是主要准确率瓶颈。** 核验前仅正确 11 条，核验后 10 条；取消核验也不足以恢复 baseline 的 20 条命中。

这些是执行记录支持的定位和架构解释，不是组件消融所证明的因果效应。当前版本作为负面实验保存；测试按用户要求停止，不自动恢复。
