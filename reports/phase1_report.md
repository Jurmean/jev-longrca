# 第一阶段：JEV 在 LongRCA-Mini 上的效果

生成时间：2026-09-21 06:35 UTC。

已完成官方固定 Mini 的 **200/200 条真实 API 评测**，5 个来源各 40 条。模型为 `jev-1.13.0`，使用固定的 JEV Choice 分段候选筛选流程；无其他模型参与推理。

## 主要结果

| 指标 | 结果 | 命中数 | 95% Wilson 区间 |
|---|---:|---:|---:|
| 责任角色准确率 | **47.0%** | 94/200 | 40.2%–53.9% |
| 根因步骤精确命中 | **19.5%** | 39/200 | 14.6%–25.5% |
| 根因步骤 ±5 命中 | **32.5%** | 65/200 | 26.4%–39.3% |

来源加权有效预测 Root MAE：**44.30 步**。有效角色输出 100.0%，有效步骤输出 100.0%。

区间是对样本命中率的描述性二项区间，未建模来源/生成模型相关性，也不表示重复运行的波动范围。

| 路径 | n | 角色准确率 | Root Exact | Root ±5 |

完整上下文与分段路径处理的样本长度、来源不同，表格不能作为方法优劣的受控对比。

分段路径 170 条的真实根因候选保留情况（事后用标签统计，不参与预测）：

| 阶段 | 含真实根因的轨迹数 | 占分段样本比例 |
|---|---:|---:|
| 各段 Top-3 合并后 | 104/170 | 61.2% |
| 加入前置交接步骤后 | 114/170 | 67.1% |
| 递归筛选到最终候选后 | 71/170 | 41.8% |
| 最终选中真实根因 | 26/170 | 15.3% |

在分段样本中，交接扩展后含真根因的 114 条中有 43 条在递归筛选时丢失；最终仍含真根因的 71 条中仅 26 条选择正确。这说明后续改进需要同时检查候选保留和最终判定，不能只提高初筛召回率。

初筛读取所有原始记录文本，超长记录按 UTF-8 无损拆片且保留 step ID。任务开头、末尾背景及候选复核阶段使用明确标记的首尾节选；因此所有文本被初筛读取，不代表最终判定同时拥有完整轨迹。详细阈值与提示词见 README 和运行配置。

按每条轨迹的合法角色集合与全部步骤均匀随机选择，解析计算的期望为：角色 26.4%、Root Exact 1.2%、Root ±5 12.5%。这是无需模型的机会水平参照，不是实测模型基线；未按标签设计固定角色预测。

- 成功 API 请求：2006 次；重试：0 次；输入 tokens：25,602,818。
- 公开单价估算：**$1.0753**，按 $0.042 / 百万输入 tokens 计算，输出免费；不是实际账单。

- 最大单请求计费输入 tokens：31,810。初始接口连通性测试 317 输入 tokens 另计，不在上述评测用量内。
- 数据固定版本：`9f45acb66948d5d20c663b4ce4ec8ea5ab0076dd`，200 个原始文件的 SHA-256 均已校验。
- 原始请求/响应、模型返回版本、用量、耗时与重试信息均在 `results/phase1/calls/`。认证头和密钥不写入结果。

## 结论边界

本次测得的是 **JEV + 已记录的上下文处理/候选筛选流程** 在此固定 Mini 上的表现。仅运行一次，未测种子/顺序稳定性，也未通过测试标签调优。
责任角色与根因步骤独立预测、独立评分；±5 是宽松辅助指标，Exact 是主要定位指标。
公开数据只提供轨迹和人工标注，没有独立 evaluator outcome 字段；只依据日志中已有的信息并告知模型运行已失败，未读取人工理由作为提示。
Mini 的来源比例、模型和方法都与论文全量实验不同，因此不能直接宣称超过/低于论文方法。下一阶段如需评估改进，需固定独立开发/验证划分或新增未用于调优的测试集，再作受控比较。
